# apk details-permissions

> Get requested permissions with details (protection_level/label/description)

## 用法

```bash
androguard-skills apk details-permissions
```

## 参数

无业务参数。

::: tip 公共参数 `--apk-path`

支持 `--apk-path <路径>` 或环境变量 `ANDROGUARD_APK_PATH`。daemon 模式下若已 `load` 可省略。

:::

## 说明

Get requested permissions with details (protection_level/label/description)
