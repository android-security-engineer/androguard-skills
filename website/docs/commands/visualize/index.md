# 📊 visualize · 可视化

> 方法控制流图（CFG）导出：DOT、图片（PNG/JPG）、JSON 三种格式。共 3 个命令。

共 **3** 个命令。

## 命令列表

| 命令 | 说明 |
|------|------|
| [`method-dot`](./method-dot) | Export method CFG as DOT format |
| [`method-image`](./method-image) | Export method CFG as image (PNG/JPG) |
| [`method-json`](./method-json) | Export method CFG as JSON |

## 用法示例

```bash
androguard-skills visualize --help    # 查看本组所有命令
androguard-skills visualize <子命令> --help
```
