# session add-apk

> Add an APK to the current Session (multi-file association analysis)

## 用法

```bash
androguard-skills session add-apk
```

## 参数

无业务参数。

::: tip 公共参数 `--apk-path`

支持 `--apk-path <路径>` 或环境变量 `ANDROGUARD_APK_PATH`。daemon 模式下若已 `load` 可省略。

:::

## 说明

Add an APK to the current Session (multi-file association analysis)

## 对应 API

`skills.session_add_apk(...)` — 详见 [Python API](../../guide/python-api)。
