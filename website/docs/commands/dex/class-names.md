# dex class-names

> Get quick class name list (without full class parsing)

## 用法

```bash
androguard-skills dex class-names
```

## 参数

无业务参数。

::: tip 公共参数 `--apk-path`

支持 `--apk-path <路径>` 或环境变量 `ANDROGUARD_APK_PATH`。daemon 模式下若已 `load` 可省略。

:::

## 说明

Get quick class name list (without full class parsing)

## 对应 API

`skills.dex_class_names(...)` — 详见 [Python API](../../guide/python-api)。
