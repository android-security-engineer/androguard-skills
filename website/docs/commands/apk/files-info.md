# apk files-info

> Get detailed file information (name/type/CRC32)

## 用法

```bash
androguard-skills apk files-info
```

## 参数

无业务参数。

::: tip 公共参数 `--apk-path`

支持 `--apk-path <路径>` 或环境变量 `ANDROGUARD_APK_PATH`。daemon 模式下若已 `load` 可省略。

:::

## 说明

Get detailed file information (name/type/CRC32)

`skills.apk_files_info(...)` — 详见 [Python API](../../guide/python-api)。
