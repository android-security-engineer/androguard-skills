# session add-dex

> Add a standalone DEX to the current Session

## 用法

```bash
androguard-skills session add-dex
```

## 参数

| 参数 | 类型 | 必填 | 默认 | 说明 |
|------|------|------|------|------|
| `<dex_path>` | path | ✅ | — |  |

## 说明

Add a standalone DEX to the current Session

## 对应 API

`skills.session_add_dex(...)` — 详见 [Python API](../../guide/python-api)。
