# apk signing-versions

> Detect APK signing schemes (v1/v2/v3/v3.1)

## 用法

```bash
androguard-skills apk signing-versions
```

## 参数

无业务参数。

::: tip 公共参数 `--apk-path`

支持 `--apk-path <路径>` 或环境变量 `ANDROGUARD_APK_PATH`。daemon 模式下若已 `load` 可省略。

:::

## 说明

Detect APK signing schemes (v1/v2/v3/v3.1)
