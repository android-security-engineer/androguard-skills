# util detect

> Detect the Android file type (APK/DEX/ODEX/ELF) of a file

## 用法

```bash
androguard-skills util detect
```

## 参数

| 参数 | 类型 | 必填 | 默认 | 说明 |
|------|------|------|------|------|
| `<filename>` | path | ✅ | — |  |

## 说明

Detect the Android file type (APK/DEX/ODEX/ELF) of a file
