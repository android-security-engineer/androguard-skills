# analysis strings-overwritten

> Get overwritten strings (is_overwritten / get_orig_value)

## 用法

```bash
androguard-skills analysis strings-overwritten
```

## 参数

无业务参数。

::: tip 公共参数 `--apk-path`

支持 `--apk-path <路径>` 或环境变量 `ANDROGUARD_APK_PATH`。daemon 模式下若已 `load` 可省略。

:::

## 说明

Get overwritten strings (is_overwritten / get_orig_value)

`skills.analysis_strings_overwritten(...)` — 详见 [Python API](../../guide/python-api)。
