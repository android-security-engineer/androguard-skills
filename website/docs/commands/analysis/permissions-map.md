# analysis permissions-map

> Get complete permissions mapping from analysis

## 用法

```bash
androguard-skills analysis permissions-map
```

## 参数

无业务参数。

::: tip 公共参数 `--apk-path`

支持 `--apk-path <路径>` 或环境变量 `ANDROGUARD_APK_PATH`。daemon 模式下若已 `load` 可省略。

:::
