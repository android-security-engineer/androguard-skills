# apk sdk-versions

> Get SDK version info (min/max/target/effective_target)

## 用法

```bash
androguard-skills apk sdk-versions
```

## 参数

无业务参数。

::: tip 公共参数 `--apk-path`

支持 `--apk-path <路径>` 或环境变量 `ANDROGUARD_APK_PATH`。daemon 模式下若已 `load` 可省略。

:::

## 说明

Get SDK version info (min/max/target/effective_target)

## 对应 API

`skills.apk_sdk_versions(...)` — 详见 [Python API](../../guide/python-api)。
