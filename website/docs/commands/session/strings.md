# session strings

> Get strings analysis across all DEXes in the Session

## 用法

```bash
androguard-skills session strings
```

## 参数

| 参数 | 类型 | 必填 | 默认 | 说明 |
|------|------|------|------|------|
| `--limit` | int | — | — | Max strings per DEX |

## 说明

Get strings analysis across all DEXes in the Session

## 对应 API

`skills.session_strings(...)` — 详见 [Python API](../../guide/python-api)。
