# session classes

> List all classes in the Session (grouped by DEX)

## 用法

```bash
androguard-skills session classes
```

## 参数

| 参数 | 类型 | 必填 | 默认 | 说明 |
|------|------|------|------|------|
| `--limit` | int | — | — | Max DEX groups to return |

## 说明

List all classes in the Session (grouped by DEX)

## 对应 API

`skills.session_classes(...)` — 详见 [Python API](../../guide/python-api)。
